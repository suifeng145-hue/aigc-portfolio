# 温健锋 AIGC 影视作品集

这是一个可以直接部署到 GitHub Pages 的静态网站。

## 上传到 GitHub 时需要上传的内容

请上传本文件夹里的全部内容，包括：

- `index.html`
- `content.js`
- `script.js`
- `style.css`
- `assets/`
- `.nojekyll`
- `README.md`

注意：不要只上传外层文件夹，要把这些文件和 `assets` 文件夹放在仓库根目录。

## GitHub Pages 设置

1. 打开 GitHub 仓库。
2. 进入 `Settings`。
3. 左侧找到 `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. `Branch` 选择 `main`，文件夹选择 `/root`。
6. 点击 `Save`。
7. 等 1 到 3 分钟，GitHub 会生成一个可以公开访问的网址。

网址通常长这样：

```text
https://你的GitHub用户名.github.io/仓库名/
```
